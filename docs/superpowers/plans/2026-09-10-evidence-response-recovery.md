# Evidence Response Recovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Recover common model response-format defects automatically so evidence extraction does not send administrators a large queue of format-only failures.

**Architecture:** Keep all factual Evidence validation unchanged. Add deterministic recovery only at the model-response boundary: parse the first complete JSON object when trailing text exists, and merge a scoped partial repair into the previously validated artifact only for server-authorized fields. A field marked `not_present` or `insufficient` may receive a neutral server-owned boundary summary when it has no sources; no supported claim, source, exact number, identity, or score is generated by recovery.

**Tech Stack:** Node.js ESM, node:test, PaperInsight weekly-report Agent Loop.

**Spec:** [WEEKLY_REPORT_AGENT_LOOP_DEV.md](../../../WEEKLY_REPORT_AGENT_LOOP_DEV.md)

## Global Constraints

- Do not weaken original-text, identity, exact-number, or cross-paper validation.
- Only repair response shape, trailing text, and empty boundary fields; preserve existing bounded content repairs.
- Never use another paper's artifacts in a repair.
- Persist administrator diagnostics with a 1,200-character redacted response limit.
- Add one regression test for every observed failure pattern.

### Task 3: Normalize empty non-claim boundary fields only

**Files:**
- Modify: `weekly-report/evidence-agent.js`
- Test: `test/weekly-report-evidence-agent.test.js`

**Interfaces:**
- Consumes: an Evidence field whose status is `not_present` or `insufficient`, whose sources are empty, and whose summary is empty or null.
- Produces: the same status and sources with a neutral server-owned boundary summary; it never changes `supported` fields.

```js
  assert.equal(validation.valid, true);
  assert.match(validation.artifacts.evidenceCard.systemDesign.summary, /原文材料未提供/);
```

- [ ] **Step 2: Run test to verify it fails**

Run: `node --test test/weekly-report-evidence-agent.test.js --test-name-pattern "neutral boundary summary"`

Expected: FAIL because schema normalization requires a non-empty summary.

- [ ] **Step 3: Write minimal implementation**

```js
const normalizeEmptyBoundaryField = (field) => (
  ["not_present", "insufficient"].includes(field?.status)
  && !Array.isArray(field?.sources)?.length
```

Apply only before `normalizeEvidenceArtifacts`; never synthesize a `supported` field or source.
