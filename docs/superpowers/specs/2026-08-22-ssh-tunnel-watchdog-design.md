# SSH 隧道守护程序设计

## 目标

为远端 `paper-insight` 服务提供一个可在本机长期运行的 SSH 隧道守护程序。它将远端 `127.0.0.1:3000` 映射到本机 `127.0.0.1:3001`，持续检查访问是否正常，并在隧道进程退出或健康检查失败时自动重连。

脚本必须提交到仓库。任意 Windows 机器在本地提供服务器地址、SSH 用户名和私钥路径后，都能安装并运行；密码、私钥、远端任务数据和 Trace 不进入仓库。

## 范围与非目标

范围：

- Node.js 守护核心与 Windows 安装、卸载、状态查看脚本。
- 使用现有 SSH 私钥创建本地端口转发。
- 对本地隧道接口进行周期性健康检查、自动重连和可读日志。
- README 中的安装和故障排查说明。

非目标：

- 不修改远端服务、数据库、历史周报、任务或 Trace。
- 不开放远端 3000 端口，不改变远端 systemd 服务。
- 不保存或提示输入 SSH 密码；仅支持密钥认证。
- 本次不实现 Linux/macOS 的 systemd 或 launchd 安装器，但 Node 守护核心保持跨平台。

## 配置与启动

守护程序通过命令行参数接收下列配置：

- `--host`：远端主机。
- `--user`：SSH 用户名。
- `--identity`：私钥绝对路径。
- `--local-port`：本地端口，默认 `3001`。
- `--remote-port`：远端端口，默认 `3000`。
- `--interval-ms`：健康检查间隔，默认 `10000`。
- `--ssh-path`：可选 SSH 可执行文件路径；未提供时使用系统 `ssh`。

安装脚本将这些值写入仅本机使用的 `.cache/tunnel-watchdog/config.json`，其目录已经被 Git 忽略。计划任务只引用仓库中的 Node 脚本和该配置文件，不包含认证内容。

计划任务以当前登录用户身份在登录后启动。该用户必须能够读取私钥并执行 Node 与 SSH。安装脚本提供 `-Install`、`-Uninstall` 和 `-Status` 三个操作。

## 守护流程

1. 启动时验证配置、私钥可读性、SSH 和 Node 可执行文件。
2. 启动由守护程序拥有的 SSH 子进程：`ssh -N -L 127.0.0.1:<local-port>:127.0.0.1:<remote-port>`，启用 `ExitOnForwardFailure=yes`、保活参数和批处理密钥认证。
3. 每个检查周期请求 `http://127.0.0.1:<local-port>/api/reading-list/jobs/active`。
4. 只要 HTTP 响应可读，保持当前 SSH 子进程。
5. 如果请求失败、SSH 子进程退出，或启动后未在一个检查周期内恢复：停止该守护程序创建的子进程，等待递增退避时间后重建隧道。
6. 收到终止信号时，仅停止自身 SSH 子进程并写入结束日志。

守护程序不会按端口号查杀其他 SSH 进程，避免干扰管理员手工创建的隧道。单个守护实例通过本机 PID 状态文件防止重复启动。

## 日志与可观测性

日志写入 `.cache/tunnel-watchdog/tunnel-watchdog.log`，每条记录包含时间、事件类型、连接状态和失败原因，不记录密钥内容、密码或 HTTP 响应正文。日志按大小轮转，保留当前文件和一个备份。

状态文件记录守护进程 PID、启动时间、最近一次成功健康检查时间、当前重连次数和子进程 PID。`-Status` 读取该文件并验证进程是否存在，以区分“已安装但未运行”和“正在运行”。

## 异常处理

- 配置缺失、私钥不存在、SSH 不可执行：退出并输出明确的本机配置错误，不进入无限重连。
- SSH 认证或网络失败：记录失败，按 2 秒、5 秒、10 秒、30 秒的上限退避重试。
- 远端服务尚未启动：健康检查失败后按相同策略重连；不会重启远端服务。
- 本地端口被其他进程占用：启动失败并给出端口和处理建议，不终止其他进程。
- 远端接口返回任意有效 HTTP 响应：视为隧道可达；不依据是否存在活动周报任务判断连接状态。

## 测试

核心守护逻辑拆分为可注入的进程启动、健康检查、时钟和日志接口，使用 Node 内置测试覆盖：

- 健康检查成功时不创建第二个 SSH 进程。
- 初次健康检查失败时终止自身子进程并按退避重连。
- SSH 子进程提前退出时重连。
- 本地端口冲突和配置缺失时停止并返回可读错误。
- 停止守护程序只终止由其创建的子进程。
- Windows 安装脚本静态检查计划任务名称、配置路径和不包含密码的参数。

## 验收标准

- Windows 机器可通过一条安装命令注册登录后自动启动的任务。
- 手工终止守护程序启动的 SSH 子进程后，日志记录断线并在退避周期内创建新的子进程。
- 浏览器可稳定访问 `http://127.0.0.1:3001`；远端隧道中断后无需手工重新执行 SSH 命令。
- 卸载操作只移除守护计划任务和本机状态文件，不删除日志、私钥、远端数据或仓库文件。
